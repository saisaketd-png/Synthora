journeys, and page hierarchy for KemKendra.

# 2. Primary User Journeys

## Guest

Search → Product → Login Prompt → Register → Continue

## Buyer

Search → Master Product → Compare Suppliers → RFQ → Reply → Direct
Business

## Supplier

Register → Become Supplier → Company Profile → Verification → Create
Listing → Admin Approval → Marketplace

# 4. Search Experience

Search by: - Product Name - CAS - Synonyms - Supplier - Category -
City - State

Ranking: 1. Sponsored 2. Exact Match 3. CAS Match 4. Product Match 5.
Verified Suppliers 6. Related Products

------------------------------------------------------------------------

# 7. RFQ Journey

Buyer - Submit RFQ - Track Status - Receive Reply

Supplier - Receive Notification - Reply in Platform or Contact Buyer
Directly - Update RFQ Status

Statuses: Submitted Viewed Replied Closed Cancelled

------------------------------------------------------------------------

# 8. Notifications

Delivery: - Internal Inbox - Email

Types: - RFQs - Verification - Product Approval - Subscription - System
Alerts

------------------------------------------------------------------------

# 9. Empty States

Examples: - No Products - No Saved Items - No RFQs - No Search Results

Each empty state includes a clear CTA.

------------------------------------------------------------------------

# 10. Error States

Supplier unavailable: Suggest similar suppliers.

Product removed: Suggest similar products.

404: Explain issue and provide links back to Search, Categories and
Homepage.

------------------------------------------------------------------------

# 11. Responsive Strategy

Desktop: Full navigation + filters.

Tablet: Collapsible sidebar.

Mobile: Bottom sheet filters, optimized tables, responsive comparison
cards.

------------------------------------------------------------------------

# 12. UX Principles

-   Marketplace first
-   Search-first experience
-   Product-centric procurement
-   Progressive authentication
-   Enterprise readability
-   Minimal clicks
-   Consistent navigation
-   Accessibility-first
