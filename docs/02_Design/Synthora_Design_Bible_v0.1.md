# Synthora Design Bible (Version 0.1)

## Design Philosophy

Synthora is not an e-commerce website and not a generic SaaS dashboard.

It is an enterprise-grade procurement platform built for chemical and
pharmaceutical professionals.

### Design Principles

-   Function before decoration
-   Enterprise-first
-   Product-centric procurement
-   Trust over visual effects
-   Consistency across every page
-   Information-rich without clutter

# UI Rules

Excessive animations - Marketing illustrations

Professional forms - Strong typography
